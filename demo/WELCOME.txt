  │  Agent Toolkit for AWS · SDLC skills                                          │
  │  AWS best practices for every phase of building software, in any agent.      │
  ╰──────────────────────────────────────────────────────────────────────────────╯

  Describe what you want to build. The agent finds the phase and applies the AWS
  guidance for it: Well-Architected, least-privilege IAM, staged rollouts, ORRs.

    intent ─► build ─► verify ─► readiness review ─► deploy ─► maintain
      ▲                                ▲                          │
      └──────── new feature ───────────┴──── readiness drift ─────┘

    aws-intent    Turns an idea into requirements and AWS architecture options
                  (serverless, containers, databases, AI) with trade-offs, live
                  pricing and regional availability, and one recommendation.
    aws-build     Infrastructure as code with AWS CDK, CloudFormation or SAM, app
                  code with the AWS SDKs, least-privilege IAM, secrets in Secrets
                  Manager, unit tests.
    aws-verify    cdk synth / cfn-lint, IAM Access Analyzer policy checks, security
                  scans, tests against a dev stack, cost against your budget.
    aws-orr       Operational readiness review: CloudWatch alarms, runbooks,
                  rollback, multi-AZ, backups, CloudTrail, budgets. Any RED item
                  blocks the production deploy.
    aws-deploy    Change-set preview, staged rollout (Lambda aliases, CodeDeploy,
                  ECS blue/green), a written rollback plan, smoke checks.
    aws-maintain  Triage from CloudWatch metrics, logs and X-Ray traces, alarm
                  gaps, Cost Explorer, runtime and engine upgrades.

  Each phase routes to deeper AWS service skills (Lambda Durable Functions, Web
  Functions, DynamoDB, Bedrock, ...) and records its work in .aws-sdlc/.

  Why it works
    AWS MCP Server   One endpoint for 15,000+ AWS APIs, live AWS documentation,
                     and service skills loaded on demand, including services
                     launched after the model's training cutoff.
    Your IAM         Every call runs under your own credentials, is logged in
                     CloudTrail, and carries the aws:ViaAWSMCPService and
                     aws:CalledViaAWSMCP condition keys for policies and audits.
    Agent Toolkit    Open source. The same skills work in Claude Code, Kiro,
                     Cursor and Codex. Install with: aws configure agent-toolkit

  Just tell it what you want to build.
